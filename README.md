# 流转

Windows x64 便携版文件转换与手机局域网互传工具。转换与传输都在本机完成，文件不经过任何服务器。

下载与使用说明见 [Releases](https://github.com/neixiangcheng/format-bridge/releases)。

- 图片与相机 RAW 导出，输出 PNG、JPEG、WebP、BMP、TIFF、PDF
- PDF 与 Word（DOCX）、Excel（XLSX）、PowerPoint（PPTX）互转，PDF 可逐页转图片
- CSV 与 XLSX 互转
- 音视频转换 MP4、MOV、MKV、MP3、WAV（需自备 FFmpeg）
- 手机与电脑连同一可信 Wi-Fi，扫码互传，单个上传最多 512 MB
