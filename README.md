# 流转

Windows x64 的文件转换与局域网文件传输工具。转换和传输都在本机完成，文件不经过任何服务器。

## 下载

到 [Releases](https://github.com/neixiangcheng/format-bridge/releases) 下载最新安装包，双击按向导安装。装到当前用户，不需要管理员权限；卸载走 Windows「设置 → 应用 → 已安装的应用」。

## 功能

- 图片与相机 RAW 导出，输出 PNG、JPEG、WebP、BMP、TIFF、PDF
- PDF 与 Word（DOCX）、Excel（XLSX）、PowerPoint（PPTX）互转，PDF 可逐页转图片
- CSV 与 XLSX 互转
- 音视频转换 MP4、MOV、MKV、MP3、WAV
- 手机与电脑连同一可信 Wi-Fi，扫码互传，单个上传最多 512 MB

安装包随附 FFmpeg，音视频转换装好即可用。
